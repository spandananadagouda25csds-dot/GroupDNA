# GroupDNA Minor Project

## Project Overview
GroupDNA analyzes WhatsApp chat exports to identify communication patterns and personality archetypes.

## Technologies Used
- Python
- NumPy
- Pandas

## Dataset
hostel_bois.txt

## Features
1. Chat parsing
2. Group overview
3. Personality archetype identification
4. Message statistics
5. Final report generation

## Personality Archetypes
1. The Spammer
2. The Group Mom
3. The Night Owl
4. The Storyteller
5. The Drama Queen
6. The Ghost
7. The Comedian
8. The Question Master

## How to Run
1. Open the notebook in Google Colab.
2. Upload the supplied hostel_bois.txt dataset.
3. Run the notebook cells in order.
4. Review the generated results.

## Limitations
Results depend on the timestamp format and the correctness of the chat parser.
Validate the results against the project brief.
